The website for aio-libs.org

## Development

Install the Python dependencies with `pip install -r requirements.txt`.

`make linkcheck` builds the site and checks it for dead links. It requires
[lychee](https://github.com/lycheeverse/lychee#installation), which can be installed with
`cargo install lychee`, from your distro's package manager, or as a prebuilt
binary from [GitHub releases](https://github.com/lycheeverse/lychee/releases).
